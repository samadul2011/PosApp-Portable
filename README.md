# PosApp-Portable

A portable Point of Sale (POS) application that runs on any Windows PC without requiring Java installation.

## ✨ Key Features

- ✅ **No Java installation required** - Includes bundled Java runtime
- ✅ **Truly portable** - Run from USB drive, network share, or any folder
- ✅ **No administrator rights required** - Works on restricted PCs
- ✅ **Zero installation** - Just extract and run
- ✅ **Self-contained** - All dependencies included

## 🚀 Quick Start

1. **Download** the latest `PosApp-Portable-1.0.0-Windows.zip` from releases
2. **Extract** to any location (Desktop, USB drive, etc.)
3. **Run** `PosApp.bat` to start the application
4. **Optional**: Create a desktop shortcut for easy access

## 📦 Distribution

Simply copy the ZIP file to:
- 💾 USB drive
- 🌐 Network share
- ☁️ Cloud storage (Google Drive, Dropbox, etc.)
- 📧 Email (if size permits)

Works immediately after extraction!

## 💡 Why Portable?

- **Works on any PC** - No setup hassles
- **IT-friendly** - No system modifications
- **User-friendly** - Non-technical users can deploy
- **Business continuity** - Run from backup location if main PC fails
- **Demo/testing** - Perfect for trials and demos
